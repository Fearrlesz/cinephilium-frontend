- Почему **100 баллов** у Metacritic? Кто это придумал?

Это **обезличивание кинематографа как искусства**.

🔥 Моя система — радикально другая

15 критериев. 5 блоков. 3 балла. Одна цель — честность.

Я разложил кино на составляющие. Не потому что я маньяк. А потому что по-другому **невозможно** оценить искусство.

| Блок | Критерии | Что это |
|------|----------|---------|
| 📋 **Сценарий** | Сюжетная архитектура | Как построена история |
| | Идейная нагрузка | Есть ли в этом смысл |
| | Диалоги | Говорят как люди или как роботы |
| 👥 **Персонажи** | Глубина | Это картонка или человек |
| | Химия | Между ними искрит или нет |
| | Функциональность | Они нужны сюжету или просто есть |
| 🎥 **Визуал** | Композиция | Как кадр собран |
| | Операторская работа | Это искусство или просто снято |
| | Темп | Не уснул ли я |
| | Эмоции | Визуал бьёт в сердце |
| 🔊 **Звук** | Музыка | Саундтрек или просто шум |
| | Звуковой дизайн | Мир звучит живым |
| | Нарративный звук | Звук рассказывает историю |
| ✍️ **Стиль** | Индивидуальность | Похоже на всё или ни на что |
| | Художественная смелость | Режиссёр рискнул или струсил |

**Каждый критерий** можно оценить отдельно. А ещё — **настроить вес** каждого блока под себя.

> Не хочешь, чтобы музыка решала всё? Поставь ей вес 5%. Сценарий — твой бог? Ставь 40%. Система подстроится. Под тебя. Под твои ценности.

💫 Три балла — не один

Потому что один балл — это **для ленивых**.

| Балл | Диапазон | Формула | Что это |
|------|----------|---------|---------|
| **Технический** | 10–100 | Строгий расчёт по критериям | Объективная реальность |
| **Вайб** | 1–10 | Твоё ощущение | Субъективная правда |
| **Комбинированный** | 10–100 | `ТБ × 0.7 + Вайб × 3` | Честный баланс |

**Технический балл** говорит: "Этот фильм сделан качественно".

**Вайб** говорит: "Мне насрать на качество, я чувствую".

**Комбинированный** — это когда ты признаёшь: и то, и другое имеет значение.

> Фильм может быть технически безупречным и **никаким**. А может быть сырым, как чёрт, и **гениальным**. Наша система это видит. Остальные — нет.

🏆 Конкурс — не для всех. Для лучшего.

Я устал от бессмысленных рейтингов. Поэтому в **Синефилиуме** рейтинг — это не просто цифра.

Ты оцениваешь фильмы → получаешь очки → поднимаешься в Топе.

Очки даются за:
- **Количество оценок** — активность
- **Качество оценок** — система видит, вдумчиво ты ставишь или просто кликаешь
- **Рецензии и комментарии** — твоё мнение имеет вес
- **Достижения** — уникальные награды за уникальные поступки
