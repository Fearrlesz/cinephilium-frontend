# F2 — гейтинг комментариев, скриншоты

- `unauth.png` — неавторизованный: «Войдите, чтобы комментировать» + ссылка `/login`, формы нет.
- `no-rating.png` — авторизован без оценки: «Чтобы комментировать, оцените фильм» + CTA «Оценить», формы нет.
- `with-rating.png` — авторизован с vibe: форма комментария доступна.
- `after-vibe.png` — гейтинг снят после сохранения vibe без перезагрузки страницы.
- `403.png` — ответ `403 RATING_REQUIRED_FOR_COMMENT`: inline-сообщение над формой, введённый текст сохранён.
- `adaptive-480.png`, `adaptive-620.png`, `adaptive-768.png`, `adaptive-1024.png` — гейт без оценки на брейкпоинтах из `DESIGN_HANDOFF.md`.

Условия: production-сборка с локальным mock API, Chrome headless, viewport 1440×1000
(адаптив — 480/620/768/1024×900). Ширина кадра комментариев — колонка `.film-main`.
Google Fonts в песочнице недоступны, поэтому системный fallback; на структуру,
цвета и поведение это не влияет.
