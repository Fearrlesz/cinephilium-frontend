# Film page redesign — скриншоты

- `before-after.png` — старое золото/стекло (слева) и новый бордо/azure (справа).
- `top.png` — герой, постер, соцдоказательство, панель трёх оценок.
- `feed.png` — «Оценили фильм», рецензии, комментарии, сайдбар.
- `modal.png` — модалка критериев (верх).
- `modal-bottom.png` — preview и кнопки сохранения.

Условия: production-сборка с локальным mock API, Chrome headless, viewport
1440×900 (top/feed — 1440×1400/2600 для полного кадра). Google Fonts в песочнице
недоступны, поэтому на скриншотах системный fallback; на структуру и палитру
это не влияет.
