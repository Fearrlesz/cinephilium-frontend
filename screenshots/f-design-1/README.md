# F-DESIGN-1 — скриншоты F1

- `before.png` — `HEAD` (`183ca44`), до слоя токенов.
- `after.png` — рабочее дерево с `tokens.css` / `base.css` / `typography.css`.

Условия съёмки: production-сборка, локальный mock API с одним и тем же фильмом,
viewport `1440×1800`, Chrome headless. Google Fonts в песочнице недоступны,
поэтому текст отрендерен системным fallback-шрифтом; на слои фона, цвета,
selection, focus и скроллбара это не влияет.

F1-разметка и компонентные CSS не менялись: на «после» виден тот же блок
оценки, но с новым глобальным фоном/цветом текста/noise из `base.css`.
