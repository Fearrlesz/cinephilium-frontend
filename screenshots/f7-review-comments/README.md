# F7 — комментарии к рецензиям, скриншоты

- `collapsed.png` — под рецензией только кнопка «7 комментариев»; страница фильма
  не разрастается списком.
- `expanded.png` — после клика: список из 5 корневых комментариев, свой pending
  с плашкой «На модерации — видно только вам», форма под списком.
- `reply.png` — ответ на комментарий: плашка «Ответ на @none», одно поле, у
  вложенного ответа нет кнопки «Ответить».
- `empty.png` — у рецензии без комментариев: «Пока никто не комментировал» и форма.
- `unauth.png` — гость видит список, но вместо формы — «Войдите, чтобы
  комментировать» и ссылка на `/login`.
- `film-mode.png` — старый режим F2 на странице фильма: комментарии к фильму,
  гейт по оценке и форма работают как раньше.
- `adaptive-480.png` — 480px: шапка блока, комментарии и форма не разъезжаются,
  горизонтального скролла нет. Дополнительно проверены 620/768/1024.

Условия: production-сборка с локальным mock API, Chrome headless/CDP,
viewport 1440×1000 (мобильный — 480px). Google Fonts в песочнице недоступны —
системный fallback; на структуру, цвета и поведение это не влияет.
