# F3 — рецензии: гейтинг и спойлер, скриншоты

- `unauth.png` — неавторизованный: «Войдите, чтобы написать рецензию» + ссылка `/login`, формы нет.
- `no-full.png` — авторизован без полной оценки: «Рецензия доступна после полной оценки — 15 критериев» + CTA «Оценить подробно», формы нет.
- `full-form.png` — авторизован с full: форма рецензии, счётчик, подсказка «Минимум 350 символов», чекбокс «Содержит спойлеры»; максимум — 15000.
- `spoiler-list.png` — спойлерная рецензия: заголовок и метаданные видны, тело скрыто под нейтральной плашкой.
- `spoiler-open.png` — плашка раскрыта, тело видно; повторный клик скрывает обратно.
- `403.png` — `403 FULL_RATING_REQUIRED_FOR_REVIEW`: inline-гейт над формой, текст и чекбокс сохранены.
- `after-full.png` — после полной оценки через `CriteriaModal` гейт снят, доступна кнопка «Написать рецензию».
- `adaptive-480.png`, `adaptive-620.png`, `adaptive-768.png`, `adaptive-1024.png` — гейт на брейкпоинтах.
- `adaptive-480-form.png` — форма с чекбоксом на 480px.

Условия: production-сборка с локальным mock API, Chrome headless/CDP, viewport 1440×1000
(адаптив — 480/620/768/1024×900). Google Fonts в песочнице недоступны — системный
fallback; на структуру, цвета и поведение это не влияет.
